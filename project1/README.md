# 项目 1：CSV 学员数据分析器

Week 3 学习作业 - 数据处理 + 文件 I/O 入门练习。

## 业务背景:对赌制度

学员报名时缴纳学费,按时完成学习则**退费奖励**,未按时完成则**不退费**。
- `active` = 还在进行中,胜负未分
- `completed` = 按时完成(老师退费)
- `failed` = 未按时完成(不退费)

## 功能

读取学员 CSV,输出统计报告(JSON):

- 总人数
- 各国家人数分布
- 对赌状态分布(三种)
- **两种完成率**:
  - 总体完成率 = `completed / 总人数`(快照视角)
  - 已结算完成率 = `completed / (completed + failed)`(真实效果)

## 文件说明

| 文件 | 说明 |
|------|------|
| `analyzer.py` | 主程序,用 Pandas 处理数据 |
| `students.csv` | 测试用假数据(15 行) |
| `report.json` | 运行后生成的统计报告 |

## 运行方式

```bash
pip install pandas
python analyzer.py
```

## 学到的知识点

- `pd.read_csv()` 读取 CSV
- `df["column"].value_counts()` 分组计数
- `dict.get(key, default)` 安全取值,避免 KeyError
- `json.dump()` 保存字典到 JSON
- `with open(...) as f:` 上下文管理器
- 业务指标设计:同一个"率",不同分母讲不同故事
